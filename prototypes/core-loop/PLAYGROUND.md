# 第一人称牌桌

## 方向

用户选择复古麻将桌或街机推币台，并询问实现成本。先采用固定第一人称的复古麻将桌，
借用街机的实体按钮与机械计分器。视觉目标是坐到桌前、拿起有厚度的麻将牌、把牌打到桌心。

参考《恶魔轮盘》的实体桌面与场景内信息表达；创作者将其描述为有沉浸感的桌面玩法、
场景内系统和精简界面：[官方介绍](https://mikeklubnika.itch.io/buckshot-roulette)。
本项目保留自己的麻将题材和复古暖灯氛围。

## 视觉约定

- 台呢绿 `#28564A`：大面积操作台，细小织物纹理。
- 木框棕 `#5A3525`：近处桌沿、磨损边角，强调坐在桌边的距离。
- 象牙白 `#F0E6CA`：麻将牌实体与记分纸，保证牌面可读性。
- 牌背绿 `#17483E`：侧面、牌山与摸牌时翻面的背部。
- 黄铜金 `#C7A367`：铭牌、机械边框与局部高光。
- 印泥红 `#B7382F`：结算实体按钮与万字、红中。

使用已有中文字体；桌上的印字小而克制，牌面与机械累计分数是主要视觉焦点。
筒以圆形图案、索以竹节图案、万以中文数字表达，字牌沿用可辨识的传统符号。

```text
                  暖灯 / 暗处房间
             [机械累计分数 / 关卡目标]
     记分纸          桌心牌河             绿色牌山
    点击展开       拖牌到此打出          点击摸牌

          眼前立起的一排手牌    新摸牌
    ─────────────── 木质桌沿 ───────────────
          操作提示             实体结算按钮
```

采用固定透视的投影桌面，手牌保持足够大、足够正；计分拆解收进可展开记分纸，
全部弃牌收进可翻看的记录本。桌心保留最近弃牌的实体排列。
设计检查：大面积分栏与常驻数据面板会削弱坐在桌边的感觉，因此改用桌上物件承载信息。

## 交互与反馈

- 摸牌：点牌山或空格；牌从牌山抬起、翻面、落在手牌右侧。
- 看牌：悬停时抬牌，显示牌名与单牌分值；等待弃牌时同步显示弃置后的得分。
- 弃牌：点击手牌打出，或拖到桌心；拖到无效位置松开则回到原位，不消耗额外资源。
- 结算：按桌边的实体按钮或回车；牌向桌心推出，记分器滚动增加，留下本次得分反馈。
- 不用动画锁住游戏输入。多次动作的视觉反馈要能结束，并回到稳定位置。
- 合成轻微牌碰撞声和按钮声；提供静音及减少动效选项。
- 固定镜头；仅允许很小的鼠标视差，减少动效时关闭。无闪屏或屏幕震动。

## 范围与验证

保留 `rules.lua`、`run.lua` 的已验证规则与随机序列。
图案、材质和声音由代码创建，不引入外部美术、音频或新库。
此阶段验证单一固定机位；暂不做自由走动、手部角色动画或真实刚体模拟。

需要检查拖拽取消、点击弃牌、视差后的命中、缩放命中、抽牌与结算动画叠加、
静音、减少动效、展开计分纸和完整弃牌记录，并继续运行原有规则检查。
最终的触感、音量和空间感仍需要玩家在实际窗口中体验。

## 当前实现与检查

2026-11-12：上述固定机位牌桌已实现，无需外部美术或音频素材。
牌面包含万字、筒圈、竹节、一索鸟形、风牌与三元牌；材质和声音使用独立的本地随机源，
不消费牌山随机序列。记录本可查看全部弃牌，桌心显示最近 24 张。
支持点击打牌、拖拽打牌、取消拖拽、抽牌翻面、结算推出与累计分数滚动。

规则检查和界面自动操作检查均通过，并检查了 1280×840 与 960×630 实际截图。
窗口模式切换曾导致 Canvas 内容丢失，现将生成贴图保存在 Image 中；画面像素检查已验证旧缓存失败、新缓存通过。
自动检查不能证明触感与音量合适，需玩家在实际窗口中体验后继续调整。
